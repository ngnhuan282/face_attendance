1. Tong quan du an

1.1. Mo ta he thong
He thong diem danh sinh vien bang nhan dien khuon mat la ung dung web xay dung tren Django, cho phep giang vien diem danh tu dong thong qua webcam. He thong nhan dien khuon mat sinh vien realtime, ghi nhan ket qua vao co so du lieu va tao bao cao chuyen can theo tung lop hoc phan.
Tinh nang chinh:
Nhan dien khuon mat realtime qua webcam (face_recognition + OpenCV)
Quan ly sinh vien, hoc phan, lop hoc phan theo mo hinh truong dai hoc
Giang vien chon lop va bat dau diem danh chi voi vai thao tac
Canh bao tu dong khi sinh vien vang > 20% tong so buoi
Xuat bao cao Excel mau sac truc quan
1.2. Cong nghe su dung

---TABLE---
Tang | Cong nghe | Muc dich
AI / Xu ly anh | face_recognition + OpenCV | Nhan dien khuon mat, xu ly video realtime
Backend | Django 4.2 + MySQL 8.0 | Web framework, quan ly du lieu
Frontend | HTML/CSS + Bootstrap 5 | Giao dien nguoi dung, hien thi video stream
Bao cao | pandas + openpyxl | Thong ke, xuat Excel
Moi truong | Python 3.11 + virtualenv + MySQL Workbench | Chay on dinh tren Windows

4.1. Cau hinh MySQL cho du an
Thay the SQLite bang MySQL yeu cau them cac buoc cai dat va cau hinh. Day la huong dan day du de ca nhom dong bo:
Cai MySQL Server 8.0: https://dev.mysql.com/downloads/mysql/
Cai MySQL Workbench de quan ly database truc quan
Cai thu vien Python: pip install mysqlclient
Neu mysqlclient loi tren Windows: pip install PyMySQL thay the

---TABLE---
CREATE DATABASE face_attendance CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;CREATE USER 'face_user'@'localhost' IDENTIFIED BY 'matkhau_manh';GRANT ALL PRIVILEGES ON face_attendance.* TO 'face_user'@'localhost';FLUSH PRIVILEGES;
-----------

---TABLE---
DB_ENGINE=django.db.backends.mysqlDB_NAME=face_attendanceDB_USER=face_userDB_PASSWORD=matkhau_manhDB_HOST=127.0.0.1DB_PORT=3306
-----------

DATABASES = {    'default': {        'ENGINE': os.getenv('DB_ENGINE'),        'NAME':   os.getenv('DB_NAME'),        'USER':   os.getenv('DB_USER'),        'PASSWORD': os.getenv('DB_PASSWORD'),        'HOST': os.getenv('DB_HOST', '127.0.0.1'),        'PORT': os.getenv('DB_PORT', '3306'),        'OPTIONS': {'charset': 'utf8mb4'},    }}
